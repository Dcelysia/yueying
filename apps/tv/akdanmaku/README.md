# AkDanmaku 本地源码

来源：Frost819/AkDanmaku，tag `1.0.2`，提交 `f599e1b6fe4d12ea27d6c6becd5d12fad20b046b`。
保留上游 `library/src/main`、LICENSE、AUTHORS；Gradle 使用本工程工具链及同版本 libGDX 原生库。

Bili Remote 修改：暂停时停止帧调度；释放先唤醒绘制等待，在计算线程清理而不阻塞 UI；新增合并更新请求的 `replaceData`，在弹幕线程替换数据，避免调节密度时重建引擎。原有追加 API 保留。

暂停时仅在配置、进度、数据或缓存发生变化时请求一次刷新，保留暂停调节样式的预览；切换等长过滤器列表也会应用新规则。

弹幕层优化：无新增或修改数据时跳过数据更新；布局单次遍历避免每帧临时列表；透明度由 View 传入每条弹幕的绘制画笔，避免普通弹幕全屏 alpha 合成，缓存未就绪时仅在单条弹幕边界内处理透明度。
