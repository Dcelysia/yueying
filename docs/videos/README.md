# 历史 Flutter 鸿蒙版产品操作演示

本目录为原生迁移前的历史记录，不作为当前 ArkTS 原生版界面、内容授权或性能证明。根 README 不再嵌入播放这些旧素材。

`product-demo.mp4` 为 2026-10-24 的真实产品操作剪辑，**51.88 秒，1600 × 1000，无音频**。画面中的手机为鸿蒙 B，电视为 Android TV 模拟器；另一部 Android 手机 A 负责选片与切片，A 的画面没有纳入成品。

## 展示步骤

1. A 已选风景视频后，B 从浏览首页右下角进入电视已有播放的占位页，继续原进度。
2. A 切换视频，B 的标题与播放状态跟随电视更新。
3. B 打开全屏控制，实际调节音量、跳转进度、暂停和恢复播放；右侧显示对应时段电视画面。

原先仅展示游戏内容流的短片已撤下。本次采用普通风景及日常视频作为背景，重点是客户端操作和电视响应，不将背景内容当作本项目作品。

## 采集与编辑边界

- TV 由系统 `screenrecord` 录制。鸿蒙模拟器缺少原生录屏工具，因此通过 HDC 连续采集设备实际帧，逐帧保留宿主机时间戳，实际采集约每秒 5–7 帧；没有伪造 UI 或做运动插帧。
- 每一章的手机与电视均来自同一采集时段，按宿主机录制起始时间及采集时间戳对齐。三章之间有剪辑，省去操作等待；没有把异时刻画面伪装成实时响应。该方式不适合用于帧率或精密延迟测量。
- 界面仅正常缩放并排显示，外侧添加操作说明；未改写标题、进度、音量或播放状态。实际跳转后出现的短暂加载没有用其他画面替换。
- 录制过程中曾尝试的另一条猫视频播放失败，没有把失败状态包装为成功步骤；成品选用已实际确认的功能片段。
- `product-preview.gif` 为完整产品演示的约 12 秒节选，960 × 600、循环播放。GIF 的 10 帧/秒是预览编码参数，不是应用运行帧率；原生 MP4 保留完整三章。
- README 还通过 GitHub 正常草稿编辑器上传原生 MP4，提供页面内点击播放；没有发布 Issue、评论或向他人发送通知。自动动图和视频播放均尊重浏览器、GitHub 及用户的播放偏好，不承诺强制视频自动播放。
